# Claude Code 對話管理

## 開啟新對話

```bash
claude
```

## 關閉後重新開啟

### 繼續最近一次的對話

```bash
claude --continue
# 或縮寫
claude -c
```

### 選擇要恢復的對話（互動式選單）

```bash
claude --resume
# 或縮寫
claude -r
```

選單操作：

| 按鍵 | 功能 |
|------|------|
| `↑` / `↓` | 瀏覽對話列表 |
| `Enter` | 選擇並恢復 |
| `P` | 預覽對話內容 |
| `R` | 重新命名 |
| `/` | 搜尋過濾 |
| `A` | 切換顯示全部專案 |

## 對話命名

在目前對話中輸入：

```
/rename 我的對話名稱
```

或開啟時直接命名：

```bash
claude --name "cc-demo開發"
```

## 快速參考

| 指令 | 功能 |
|------|------|
| `claude` | 開啟新對話 |
| `claude -c` | 繼續最近一次對話 |
| `claude -r` | 互動式選單選擇對話 |
| `claude -r "名稱"` | 恢復指定名稱的對話 |
| `claude --name "名稱"` | 開啟時直接命名 |
| `/rename 名稱` | 在對話中重新命名 |
| `/resume` | 在對話中切換到其他對話 |

> **建議**：每次開始重要的對話前先 `/rename`，之後用 `claude -r` 就能快速找回。
