## 什麼是 MCP？

**MCP (Model Context Protocol)** 是 Antigravity Editor 與本地工具、資料庫以及外部服務之間的安全橋樑。

MCP 消除了手動提供情境資訊的需要（例如複製貼上日誌或 schema），讓 AI 能夠即時直接擷取這些資訊。

---

## 核心功能

### 1. Context Resources（情境資源）

AI 可以從連接的 MCP 伺服器讀取資料，以增強其建議品質。

**實際應用範例：**
- **SQL 查詢輔助**：當撰寫 SQL 時，可以檢查即時的 **Neon** 或 **Supabase** schema，建議正確的資料表和欄位名稱
- **除錯輔助**：在除錯時，可以從 **Netlify** 或 **Heroku** 拉取最近的建置日誌

### 2. Custom Tools（自訂工具）

MCP 讓 AI 能夠執行連接伺服器定義的特定、安全操作。

**實際應用範例：**
- 「為這個 TODO 建立一個 Linear issue」
- 「在 Notion 或 GitHub 中搜尋認證模式」

## 如何連接 MCP 伺服器

### 方法一：透過內建 MCP Store 連接

1. **開啟 MCP Store**
   - 點擊編輯器側邊面板/Agent 面板頂部的「...」（更多）下拉選單

2. **瀏覽並安裝**
   - 選擇支援的伺服器
   - 點擊「Install」

3. **驗證**
   - 依照提示安全地連結您的帳戶

安裝完成後，伺服器的資源和工具將自動對編輯器可用。

### 方法二：連接自訂 MCP 伺服器

對於私有或自建的伺服器，可以手動設定：

1. 開啟 **MCP Store**
2. 點擊 **「Manage MCP Servers」**
3. 點擊 **「View raw config」**
4. 直接修改 `mcp_config.json` 檔案，加入您伺服器的設定詳細資訊

## MCP 設定檔範例

`mcp_config.json` 檔案的基本結構：

```json
{
  "mcpServers": {
    "server-name": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-example"],
      "env": {
        "API_KEY": "your-api-key"
      }
    }
  }
}
```

### 常見設定範例

#### PostgreSQL 資料庫（Neon）
```json
{
  "mcpServers": {
    "neon": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:password@host:5432/dbname"
      }
    }
  }
}
```

#### GitHub 整合
```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "your-github-token"
      }
    }
  }
}
```

#### Supabase 整合
```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-supabase"],
      "env": {
        "SUPABASE_URL": "https://your-project.supabase.co",
        "SUPABASE_KEY": "your-api-key"
      }
    }
  }
}
```

## Skills vs MCP 的區別

| 特性 | Skills | MCP |
|------|--------|-----|
| **架構** | 檔案式、無伺服器的任務定義 | 用戶端-伺服器架構 |
| **連接** | 不需要持續連接 | 設計用於有狀態連接 |
| **用途** | 擴展 Agent 的任務能力 | 連接外部系統和服務 |
| **儲存位置** | `.agent/skills` 目錄 | `mcp_config.json` 設定檔 |
