## 在 Antigravity 中設定

### 步驟 1：開啟 MCP 設定

1. 點擊右側 Agent 面板的「...」
2. 選擇「MCP Store」→「Manage MCP Servers」→「View raw config」

### 步驟 2：新增自訂 Server

在 `mcp_config.json` 中加入：

```json
{
  "mcpServers": {
    "mcp-server-demo": {
      "command": "java",
      "args": ["-jar", "C:\\Users\\rexre\\IdeaProjects\\JavaExample\\McpServerDemo\\target\\McpServerDemo-0.0.1-SNAPSHOT.jar"]
    }
  }
}
```

### 步驟 3：重新載入 MCP Servers

儲存後重新載入，即可使用自訂工具！
